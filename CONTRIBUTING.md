# Faire évoluer FrostPulse ensemble

Merci de prendre le temps de contribuer au projet. Je souhaite que cet espace facilite les retours utiles et les échanges entre passionnés, en français comme en anglais.

## Signaler un bug

Recherchez d'abord dans les Issues pour voir si le problème est déjà signalé. Utilisez ensuite le formulaire de bug en précisant la version de FrostPulse, le GPU, le pilote, Windows et les étapes pour reproduire le problème. Une capture de l'interface peut aider ; retirez les informations personnelles avant de la partager.

## Proposer une amélioration

Utilisez les Discussions pour expliquer votre besoin et échanger avec les autres utilisateurs. Une suggestion est plus utile si elle décrit une situation concrète et le résultat attendu. Le formulaire de suggestion dans les Issues est également disponible.

## Partager sa configuration

Précisez le modèle exact de la carte, sa capacité mémoire, le pilote, la version de FrostPulse et les sondes ou réglages disponibles. Cela aide à documenter la compatibilité sans généraliser à toute une famille de GPU.

## Corriger la documentation

Les corrections de traduction, les explications plus claires et les guides utiles sont les bienvenus. Les pull requests concernent la documentation de ce dépôt ; le code source de l'application n'y est pas publié.

## Échanger

Restez courtois et concret. Les désaccords techniques et les retours négatifs sont utiles lorsqu'ils sont expliqués et respectueux. Évitez le spam, les attaques personnelles et le partage d'informations privées.

Retrouvez la communauté sur le [Discord FrostPulse](https://discord.gg/ETk7XmNFpB).

## English

You can help by reporting reproducible bugs, sharing your exact GPU setup and available features, explaining improvement ideas, or correcting documentation and translations. Check existing Issues before opening a new report. Use Discussions for questions and feedback. Documentation pull requests are welcome; the application source code is not published in this repository.

Please keep exchanges respectful and useful, and remove personal information before posting screenshots or logs.
